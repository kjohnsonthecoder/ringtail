Privacy policy

Ringtail web page and the Ringtail "Highlight to Detect" browser extension. Last updated 18 November 2026.

The short version

  • Ringtail has no accounts, no analytics, no ads, and no tracking.
  • Your Anthropic API key never reaches the Ringtail server. It goes only from your browser to Anthropic.
  • The text you choose to analyze goes to the Ringtail server to build a prompt and run checks, and to Anthropic to draft the rule. The Ringtail server doesn't store it.
  • Nothing is sold or shared with anyone else.

What data is handled, and where it goes

Your Anthropic API key. You type it in. It's sent only to api.anthropic.com to call Claude. On the web page it lives in the page's memory and is gone when you close or reload the tab. In the extension it's kept in the browser's session storage: in memory, cleared when the browser quits, never written to disk, and not readable by websites. The Ringtail server refuses any request that carries a key.

Text you choose to analyze. On the web page, what you type or paste. In the extension, only the text you highlight and send with "Detect with Ringtail", which you can edit before anything is sent. The extension can't read the pages you visit. This text goes to:

  • the Ringtail server, which cleans it into plain text, builds the prompt, and runs the checks on the draft rule. It's processed in memory and not stored, and server logs record request paths only, never request contents;
  • Anthropic, under your own API key and your own agreement with Anthropic, to draft the rule.

Drafts and results. The draft rule and samples Claude returns go to the Ringtail server for checking, then are shown to you. They aren't stored on the server.

Access code (only if a server owner turns one on). Sent only to that Ringtail server, never to Anthropic. In the extension it's kept in session storage like the key.

Extension settings. The server address and model name you choose are saved in the browser's local extension storage on your device. They aren't secret and never leave your browser except as the address the extension connects to.

Network metadata. Like any website, the server and its host (Railway) see your IP address, which the server uses in memory to rate-limit requests. It isn't stored by Ringtail.

What Ringtail doesn't do

  • No cookies, no analytics, no third-party scripts, no advertising.
  • No access to your browsing history or the content of pages you visit.
  • No selling, renting, or sharing of data, and no use of data for anything other than drafting and checking detection rules.

Self-hosting and contact

Ringtail is open source (MIT). You can run your own server and point the extension at it, in which case your text goes to your server instead. The code, threat model, and design decisions are public: github.com/kjohnsonthecoder/ringtail. Questions or concerns: open an issue there.
